# 👟 Shoes E-Commerce Store

A **Full Stack Shoes E-Commerce Store** built with **HTML, CSS, Bootstrap, JavaScript, PHP, and MySQL**. This project provides a modern online shopping experience where customers can browse products, place orders, and administrators can manage products and customer orders through a secure admin dashboard.

## 🚀 Features

### Customer Side

* Responsive Home Page
* Product Listing
* Product Details Page
* Order/Checkout Form
* Order Confirmation (SweetAlert)
* Mobile-Friendly Design

### Admin Panel

* Secure Admin Login
* Dashboard
* Add Products
* Update Products
* Delete Products
* Manage Customer Orders
* Image Upload Support

## 🛠️ Tech Stack

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* PHP
* MySQL
* Font Awesome
* SweetAlert2
